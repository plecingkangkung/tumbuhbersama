# Project workflow

The user has authorized committing and pushing completed changes in this repository to https://github.com/plecingkangkung/tumbuhbersama after relevant checks pass. Apply this workflow to future requested changes unless the user says otherwise.

- Inspect the working tree and fetch the remote before publishing. Preserve unrelated user changes.
- Commit the requested changes with a clear message and push the current project branch to origin. Never force-push or overwrite remote history without explicit authorization.
- Do not commit .env, credentials, database contents, node_modules, or build output.
- Report the resulting commit and any checks or push failures honestly. A push does not mean the website has been deployed.
